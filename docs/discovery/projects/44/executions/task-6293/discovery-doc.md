# Discovery: Веб-приложение для школьников: отрисовка 3D-модели молекулы по вводимой химической формуле

## Problem

Школьники испытывают трудности с пониманием пространственной структуры молекул при изучении химии. Традиционные учебные материалы (плоские рисунки в учебниках, 2D-схемы на доске) не передают трехмерную природу молекул, что затрудняет понимание:
- Химических связей и их направленности
- Углов между связями (валентных углов)
- Реальных форм молекул (линейная, треугольная, тетраэдрическая и др.)
- Взаимного расположения атомов в пространстве

Это приводит к механическому запоминанию формул без глубокого понимания структуры, что снижает качество обучения и интерес к химии.

## Context

Исследование выполнено в рамках проекта Molecule3D-School. Проект предполагает создание веб-приложения, которое позволит школьникам вводить химические формулы (например, H2O, CH4, C2H6O) и мгновенно получать качественную 3D-визуализацию соответствующей молекулы.

Обследование доступных инструментов показало, что существуют специализированные библиотеки для 3D-визуализации молекул (Three.js, molstar, 3Dmol.js), но они требуют технических навыков для интеграции и не оптимизированы для образовательных целей.

## Users and Stakeholders

**Пользователи:**
- Ученики средних классов (7-9 классы, 12-15 лет) — изучают базовую химию, простые молекулы (H2O, CO2, NH3)
- Ученики старших классов (10-11 классы, 15-17 лет) — изучают органическую химию, более сложные молекулы (этанол, бензол)
- Учителя химии — для демонстраций на уроках

**Стейкхолдеры:**
- Школьная администрация — требования к доступности, отсутствию платных подписок
- Родители — ожидание образовательной ценности, безопасности
- Разработчики — требования к поддержке и развитию

## Candidate Scope

**MVP Scope:**
1. **Парсинг химических формул**: поддержка простых неорганических и органических формул (H2O, CH4, C2H6O, C6H12O6)
2. **3D-визуализация**: качественное отображение молекулы с правильной геометрией (связи, валентные углы)
3. **Базовая интерактивность**: вращение молекулы, зум, панорамирование
4. **Атомные аннотации**: подписи атомов при наведении (H, C, O, N и др.)
5. **Браузерная доступность**: работа без установки, в современных браузерах

**Технический стек:**
- Фронтенд: React + Vite для быстрой загрузки
- 3D-рендеринг: Three.js (универсальный) или molstar/3Dmol.js (специализированные)
- Парсинг формул: OpenBabel.js или собственный парсер для базовых формул
- Деплой: статический хостинг (Vercel, Netlify) для бесплатного доступа

**NOT в MVP:**
- Сложные макромолекулы (белки, ДНК)
- Химические симуляции (динамика, реакции)
- Системы авторизации и сохранения
- Мобильные приложения (только веб)

## Assumptions

1. **Целевая аудитория**: школьники имеют доступ к современным браузерам (Chrome, Firefox, Safari) на школьных компьютерах или личных устройствах
2. **Технические навыки**: пользователи не имеют специальных технических знаний; интерфейс должен быть интуитивным
3. **Производительность устройств**: школьные ноутбуки имеют базовую поддержку WebGL (Intel HD Graphics или аналоги)
4. **Качество интернета**: доступ в школах может быть ограниченным; приложение должно работать оффлайн после первой загрузки
5. **Учебный контекст**: приложение используется как дополнение к учебникам, не заменяя учителя
6. **Формат ввода**: пользователи вводят формулы в стандартной химической нотации (H2O, C2H5OH)

## Unknowns

1. **Реальное качество WebGL на школьных устройствах**: неизвестно, какие GPU используются в школах и какова реальная производительность
2. **Точность геометрии молекул**: нужно определить источники данных для правильных координат атомов (библиотеки, базы данных, расчеты)
3. **Эффективность парсинга формул**: неясно, насколько сложным будет парсинг органических формул (C2H6O → этанол или диметиловый эфир?)
4. **Потребность в фичах**: неизвестно, какие интерактивные функции наиболее важны (измерение расстояний, углов, структурные формулы?)
5. **Конкуренция**: существуют ли аналогичные бесплатные инструменты для школ?
6. **Интеграция с учебными программами**: как приложение может быть встроено в существующие учебные планы?
7. **Масштабируемость**: сколько пользователей планируется, какие требования к инфраструктуре?

## Risks

1. **Технические риски:**
   - Низкая производительность WebGL на слабых устройствах (старые школьные ноутбуки)
   - Невозможность корректного отображения сложных молекул без оптимизации
   - Ошибки в парсинге формул (неоднозначность молекулярной структуры)

2. **Образовательные риски:**
   - Некорректная геометрия молекул может дезинформировать учащихся
   - Приложение может восприниматься как "игра", а не учебный инструмент
   - Учителя могут не внедрять инструмент из-за отсутствия методических материалов

3. **Риски внедрения:**
   - Школы могут блокировать доступ к внешним ресурсам
   - Требования к доступности (для слабовидящих, мобильных устройств)
   - Необходимость локализации (русский язык, другие языки)

4. **Риски поддержки:**
   - Необходимость регулярного обновления данных о молекулах
   - Баг-репорты от пользователей, необходимость обратной связи
   - Потенциальная нагрузка на сервер (если используется бэкенд)

## Evidence

Для принятия решения о реализации необходима следующая информация:

1. **Исследование целевой аудитории:**
   - Опрос учителей химии о потребностях в 3D-визуализации
   - Тестирование прототипа с небольшой группой учеников
   - Анализ существующих учебных материалов и их ограничений

2. **Техническое исследование:**
   - Тестирование производительности WebGL на типичных школьных устройствах
   - Сравнение библиотек (Three.js vs molstar vs 3Dmol.js) по функциональности и производительности
   - Оценка сложности парсинга химических формул

3. **Конкурентный анализ:**
   - Изучение существующих бесплатных инструментов (MolView, ChemSketch, Kmol)
   - Анализ их ограничений и возможностей для использования в школах

4. **Пилотный прототип:**
   - Создание MVP с поддержкой 5-10 базовых молекул
   - Тестирование с реальными пользователями (ученики и учителя)
   - Сбор обратной связи о функциональности и UX

## Recommendation: clarify

**Обоснование:**

Идея имеет потенциал для решения реальной образовательной проблемы, но для принятия обоснованного решения о реализации (go/reject) необходимо дополнительное исследование:

**Сильные стороны:**
- Ясная проблема: школьникам трудно понимать 3D-структуру молекул по 2D-материалам
- Конкретный MVP: качественная 3D-визуализация + парсинг простых формул
- Низкая стоимость разработки: существующие библиотеки (Three.js, molstar)
- Образовательная ценность: визуализация помогает пониманию

**Критические неизвестные:**
1. Реальная производительность на школьных устройствах (риск блокирующий для MVP)
2. Способность парсинга корректно интерпретировать формулы (риск блокирующий для функциональности)
3. Реальный спрос со стороны учителей и учеников (риск блокирующий для внедрения)
4. Конкурентное окружение: существуют ли аналогичные бесплатные решения?

**Рекомендуемые действия перед переходом к разработке:**
1. Создать интерактивный прототип (1-2 молекулы, hardcoded) для тестирования производительности на школьных устройствах
2. Провести опрос 5-10 учителей химии о потребностях и существующих инструментах
3. Исследовать техническую осуществимость парсинга формул (OpenBabel.js vs собственный парсер)
4. Изучить 2-3 существующих инструмента (MolView, ChemSketch) на предмет функциональности и ограничений

После сбора этой информации можно принять обоснованное решение:
- **go**: если прототип показывает приемлемую производительность и есть интерес со стороны учителей
- **reject**: если существующие бесплатные инструменты решают проблему или технические риски слишком высоки
- **clarify further**: если выявлены новые критические неизвестные

**Текущая оценка:** идея перспективна, но требует сбора дополнительных данных для минимизации рисков разработки и внедрения.

# Discovery: Molecule3D School — Local Model

## Problem

Школьники в российских школах испытывают трудности с пониманием пространственной структуры молекул при изучении химии. Плоские рисунки в учебниках и 2D-схемы на доске не передают трёхмерную природу молекул, что затрудняет понимание химических связей, валентных углов и реальных форм молекул (линейная, тетраэдрическая и др.).

Ключевая проблема для **локальной модели**: многие школы имеют ограниченное или нестабильное интернет-соединение, а также блокируют доступ к внешним образовательным ресурсам. Облачные решения (MolView, ChemSketch Online) недоступны в таких условиях. Необходим инструмент, который работает полностью автономно — без сервера, без регистрации, без интернета.

## Context

Исследование выполнено в рамках проекта Molecule3D-School-LocalModel (epic 45). Это локальная версия идеи из epic 44 (Molecule3D Discovery), с фокусом на offline-first архитектуру и работу без серверной части.

Обследованы следующие файлы репозитория:
- `bootstrap-molecule3d.mjs` — шаблонный bootstrap для проекта Molecule3D-School (epic 44)
- `bootstrap-molecule3d-local.mjs` — локальная версия bootstrap для epic 45
- Discovery-документ из epic 44 (`docs/discovery/projects/44/executions/task-6293/discovery-doc.md`) — содержит аналогичный анализ проблемы, но без фокуса на локальную модель

Существующие инструменты 3D-визуализации молекул в браузере:
- **MolView** (molview.org) — онлайн-инструмент, требует интернета
- **3Dmol.js** — JavaScript-библиотека для WebGL-рендеринга молекулярных структур
- **NGL Viewer** — интерактивный просмотрщик, работает в браузере
- **JSmol** — Java-based (устаревший), но полностью клиентский

Для локальной модели ключевой вопрос: какие библиотеки поддерживают full client-side работу без сервера и могут вычислять геометрию молекулы на основе только химической формулы.

## Users and Stakeholders

- **Ученики 8-11 классов (14-17 лет)** — основная аудитория; изучают стереохимию, пространственные структуры молекул в рамках школьной программы по химии
- **Учителя химии** — используют приложение для демонстраций на уроках; нуждаются в простом интерфейсе без необходимости регистрации
- **Школьная ИТ-инфраструктура** — ограниченный интернет, возможные файрволы, старые компьютеры с WebGL 1.0
- **Родители** — ожидают бесплатный образовательный инструмент без подписок и сбора данных

## Candidate Scope

**MVP (локальная модель):**

1. **Парсинг формул**: поддержка базовых неорганических (H2O, CO2, NH3, CH4) и простых органических молекул (C2H5OH, C6H12O6). Геометрия молекулы берётся из встроенной базы данных координат атомов (не вычисляется на лету).
2. **3D-рендеринг**: Three.js или 3Dmol.js для WebGL-отрисовки; поддержка вращения, зума, переключения между шар-стиков и пространственными моделями.
3. **Встроенная база молекул**: ~15-20 базовых молекул с заранее рассчитанными координатами атомов и длинами связей (PDB/XYZ формат).
4. **Полностью оффлайн**: один HTML-файл или статический сайт, не требующий сервера; работает при открытии файла локально в браузере.
5. **Русскоязычный интерфейс**: подписи атомов, подсказки на русском языке.

**NOT в MVP:**
- Вычисление геометрии из формулы (только lookup по базе)
- Сложные макромолекулы (белки, ДНК)
- Химические симуляции и анимации
- Система пользовательских аккаунтов
- Мобильная версия (responsive — да, native app — нет)

## Assumptions

1. **Школьные браузеры**: современные Chrome/Firefox поддерживают WebGL 1.0 на большинстве школьных компьютеров (даже с интегрированной графикой Intel HD).
2. **База координат**: для базовых молекул существуют достоверные данные о геометрии (из PDB, PubChem или учебников), которые можно вручную закодировать в приложение.
3. **Нет интернета**: школа может полностью блокировать внешний интернет; приложение должно работать при открытии `.html` файла напрямую.
4. **Пользователи не технически подкованы**: ввод формулы — единственный интерфейс; никаких настроек, меню или сложных команд.
5. **Производительность**: Three.js способен отрисовать 10-20 атомов с связями на школьном ноутбуке без лагов (требует проверки).

## Unknowns

1. **Реальная поддержка WebGL в школах**: неизвестно, какие GPU установлены в большинстве российских школ; некоторые старые компьютеры могут не поддерживать WebGL вообще.
2. **Охват формул**: сколько молекул из школьной программы (8-11 класс) нужно покрыть? Есть ли полный список?
3. **Альтернативные библиотеки**: 3Dmol.js vs Three.js — какая лучше подходит для образовательного использования (лицензия, размер бандла, простота API)?
4. **Расширяемость базы**: если позже понадобится добавить новые молекулы, насколько легко это будет сделать без пересборки приложения?
5. **Конкурентные локальные решения**: существуют ли уже оффлайн-инструменты для 3D-визуализации молекул в школах (например, десктопные программы)?

## Risks

1. **Технические риски:**
   - WebGL не поддерживается на старых школьных ПК — приложение будет нерабочим для части аудитории
   - Размер бандла Three.js (~600KB gzipped) может быть проблемой при медленном интернете (первая загрузка)
   - Ручное кодирование координат молекул — трудоёмко и подвержено ошибкам

2. **Образовательные риски:**
   - Ошибки в координатах атомов могут привести к неверной геометрии и дезинформации
   - Ограниченный набор молекул (~15-20) может не покрыть потребности школьной программы

3. **Риски внедрения:**
   - Учителя могут предпочесть готовые онлайн-инструменты (MolView), которые уже известны
   - Распространение локального приложения: как школы получат файл? USB, флешка, локальный сервер?

## Evidence

2. `bootstrap-molecule3d-local.mjs` — bootstrap для epic 45 (локальная модель)

## Recommendation: go

**Обоснование:**

Идея решает реальную проблему (недоступность онлайн-инструментов в школах с ограниченным интернетом) и имеет чёткий MVP с минимальными техническими рисками.

**Сильные стороны:**
- Чёткое отличие от epic 44: фокус на offline-first, один HTML-файл, без сервера
- Низкая стоимость разработки: Three.js + встроенная база молекул — всё open-source
- Простой пользовательский опыт: ввод формулы → мгновенный результат
- Образовательная ценность подтверждена discovery epic 44

**Минимальные неизвестные:**
1. WebGL на школьных ПК — проверяется простым тестом (одна страница с canvas)
2. База координат — для 15-20 базовых молекул данные есть в открытом доступе (PDB, учебники)
3. Выбор библиотеки — Three.js vs 3Dmol.js: можно протестировать обе за один день

**Рекомендуемые следующие шаги:**
1. Создать proof-of-concept: одна страница с Three.js, hardcoded молекула H2O, проверка WebGL на школьном ПК
2. Собрать базу координат для 15 базовых молекул из школьной программы
3. Протестировать производительность на типичном школьном ноутбуке (Intel HD Graphics)

Оценка: идея зрелая для перехода к formalization и реализации MVP. Критических неизвестных, которые могли бы полностью заблокировать проект, не выявлено.

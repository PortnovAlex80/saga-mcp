## КОРРЕКТИВКА ОТ ИСПОЛНИТЕЛЯ (implementer, ветка repair/worker-disorientation) ✅

**Теория «AGENTS.md-подъёма» Д1 ОПРОВЕРГНУНА экспериментом** (10 прогонов
в лаборатории с точной топологией завода и точным спавном шима — ascent не
воспроизводится маркерами). Истинный механизм найден в коде opencode 1.18.18
(Cli.run, извлечён из бинарника): база сессии =
`path.resolve(process.env.PWD ?? process.cwd())` — **унаследованный env.PWD
побеждает истинный cwd**. Дерево процессов завода наследует PWD от шелла
оператора в корне saga-mcp → каждая сессия якорится в корне завода.
Доказательства: живая БД opencode — 139 board-сессий с directory =
главный корень; эксперимент E10 (cwd=product + env.PWD=main → сессия в
main) — 100% воспроизводимость. Пининг: флаг `--dir` у `opencode run`
(OPENCODE_*-env для directory нет).

**Реализовано (2 коммита, RED-first, 522/0 process-modules, E2E на реальном
opencode):** шим читает --cwd (fallback: cwd шима) и пинит тремя способами
(--dir в argv, override env.PWD, явный cwd спавна + громкая stderr-нота при
конфликте); маркер AGENTS.md — дублирующая сеть для marker-based резолюций
(механизм env.PWD маркером не лечится — показано E9), применяется к будущим
песочницам через выделенный провижининг-модуль. Эмпирика Д3 (72% сессий,
~50-60 мин налога, тихие чтения) остаётся валидной — меняется только
механизм-объяснение.

- **Механизм (Д1)**: opencode 1.18.18 ищет workspace-маркер вверх от cwd;
  продуктовый репо без маркера → база = AGENTS.md главного репо.
- **Невиновность (Д2)**: раннер и контракт путей корректны.
- **Цена (Д3)**: системный, самовылечивающийся налог ~1 мин/сессия +
  замаскированные чтения неверного контента + 1 смерть из 5.

Фиксы (выбор после терминала, эксперимент в песочнице):
1. **Правильный**: пининг директории сессии из шима (env/флаг opencode) —
   явный контракт, чинит и тихие чтения.
2. **Дешёвый**: AGENTS.md-маркер в продуктовый репо при инициализации
   песочницы — закрывает ascent, но полукостыль (сигнал боковым каналом).
3. **Дополнительно рассмотреть**: абсолютные пути в промпте вместо
   относительных (ломается переносимость desk'а) — отклонено Д2-аргументом,
   что контракт был согласован; менять его ради чужого бага — дорого.

Отдельно в реестр дефектов: спавн-fencing-баг «process birth identity is
unavailable» (3 lost на task 28) — не связан с дезориентацией.

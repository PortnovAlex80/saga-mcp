## 2. Lineage invariants (checked mechanically where decidable)

1. **Authority conservation** (ADR-053 test 1): Gate.subject == CandidateSet ==
   Effect.input == FinalAcceptance.candidate == downstream product — matrix-
   hosted via factory-contract/architecture groups; adversarial variants
   (newer execution/task/unrelated submission) are corpus scenarios.
2. **Cardinality conservation** (ADR-053 test 3): frozen atomic members ==
   SRS §D2 members == Solution Contract criteria == DevelopmentCase criteria —
   matrix-hosted (`development-constraint-relay`, criterion-identity
   separation commit f13181e0 metamorphic N-documents ≡ 1-container).
3. **Digest continuity**: every AL row's consumer re-verifies by exact ref +
   hash before use (BM-2..BM-13); the two known recency hazards
   (epic accumulation, capsule binder) plus SM-14 are the declared residuals —
   LINEAGE IS NOT CLAIMED CLOSED over them.

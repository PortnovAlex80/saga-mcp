# Go-to-Market: заработать на Production Fabric — Россия, затем Европа

Бизнес-ресёрч и план. Дата: 2026-08-17. Основано на четырёх параллельных
веб-исследованиях (плейбук Palantir/Bentley/Veeva; рынок РФ; путь в ЕС;
экономика GLM) + аудит собственных активов. Все ключевые факты с URL;
оценки помечены [О].

---

## 1. Резюме (главное)

1. **«Российский Палантр» — правильная амбиция, но неправильная категория
   для продажи.** Palantir шёл к первому значимому доходу 8 лет (2011,
   ~$250 млн, единственный клиент — ЦРУ), к прибыльности — 20 лет
   ([Wikipedia](https://en.wikipedia.org/wiki/Palantir),
   [Barron's](https://www.barrons.com/articles/palantir-earnings-stock-price-7d996fd1)).
   Без гос-якоря уровня In-Q-Tel эта траектория невоспроизводима. Все
   успешные аналоги начинали с одного вертикального клина: Veeva (фарма),
   Bentley (просмотрщик CAD для DuPont), Celonis (логи SAP). **Наш клин:
   экспертизо-готовые расчётные тома (опоры → ж-д → ПГС) за дни вместо
   недель.** Платформа — результат 5–10 лет поставок, не стартовая позиция.
2. **Окно в РФ реально открыто.** Полного аналога Palantir в РФ нет —
   публично подтвердил депутат ГД Журавлёв (май 2026,
   [Lenta](https://lenta.ru/news/2026/05/14/v-rossii-otsenili-riski-ot-primeneniya-vsu-sistemy-palantir/)).
   Рынок инженерного ПО РФ ~34–55 млрд ₽ (2024–2025,
   [TAdviser](https://www.tadviser.ru/index.php/Статья:Инженерное_программное_обеспечение_(рынок_России)));
   в госзакупках САПР 93,4% — российские, но реально используется лишь
   15–20% лицензий ([CNews](https://www.cnews.ru/news/top/2024-06-14_rossijskie_sapr_zakupayutsya))
   — разрыв «деньги идут, использование не идёт» = спрос на инструменты,
   которые реально работают. ТИМ обязательны с 2022 (госзаказ) и с 2024–2025
   (жильё, МКД/ИЖС) — регуляторный попутный ветер
   ([ПП №331](https://base.garant.ru/400424628/)).
3. **GLM — это рентабельность, но не фундамент.** Токен GLM в 5–10 раз
   дешевле Claude [О]; но личная подписка Coding Plan **юридически не может
   быть производственной базой коммерческого продукта** (ToS запрещают
   resell/multi-user, Z.ai банит —
   [Usage Policy](https://docs.z.ai/devpack/usage-policy)). Легально:
   API-биллинг или Team-план (~$85–170/место). Архитектура у нас уже
   модель-агностична (конвейер §1) + open-weights GLM (MIT) на 2×4090 для
   суверенных клиентов — страховка от Entity List-риска.
4. **Формула выручки — «треугольник BYO-plan».** Мы зарабатываем на
   фабрике (подписка/лицензия у каждого юрлица-клиента); Z.ai зарабатывает
   на том, что **каждое юрлицо, поставившее фабрику, покупает свой
   собственный GLM Team-план** (≈$85–170/место/мес). Мы не перепродаём
   квоты — клиент владеет своим планом, ToS соблюдены. Инцентивы
   выровнены: каждый наш деплой = новый подписчик Z.ai → на этапе
   10–20 развёртываний это аргумент для прямого партнёрства
   (публичной партнёрской программы у Z.ai нет; вход — через
   [bigmodel.cn](https://bigmodel.cn/) 商务合作 / enterprise sales
   [Z.ai](https://z.ai/); нюанс: [open.z.ai развёрнут не глобально](
   https://github.com/openclaw/openclaw/issues/63687), часть продуктов —
   только через open.bigmodel.cn).
5. **Формула старта: «услуги на своей фабрике → продукт».** Это модель
   forward-deployed engineers Palantir и полевых инженеров Bentley:
   доход с первого месяца, каждая поставка кодифицируется в продукт.
   Первые деньги: расчётные тома для проектных бюро (себестоимость токенов
   $1–10 на том [О], цена рынка — сотни тысяч ₽).
6. **Европа — только через полную релокацию.** Прямого общеевропейского
   запрета покупать ПО у российских владельцев нет, но платежи (18/19-й
   пакеты — [Еврокомиссия](https://finance.ec.europa.eu/news/eu-adopts-19th-package-sanctions-against-russia-2025-10-23_en)),
   банковский de-risking и прецедент Kaspersky делают продажи от юрлица РФ
   неработающими. Путь: чистое международное юрлицо + релокация основателя
   (Нидерланды/Германия/Франция/Португалия; Эстония и Польша для
   РФ-резидентов закрыты), вход в ЕС как модуль к CDE (Thinkproject, Dalux,
   Nemetschek), а не замена. EIC Accelerator требует регистрации в
   ЕС/associated ([EIC](https://eic.ec.europa.eu/eic-funding-opportunities/eic-accelerator_en)).

## 2. Что мы имеем (честный инвентарь)

**Активы:**
- Движок: 1802 коммита, 486 TS-файлов (~148 тыс. строк), 342 теста;
  конвейерная физика (workplaces/gates/sealed revisions/replay/effects/
  recovery epochs/supervisor) — единственный в своём классе в РФ [О].
- Работающая вертикаль GDesign: расчёт опоры ОДН (МКЭ + SCAD-свидетель,
  2,3% отклонение), 35-страничный PDF-том end-to-end, Web-UI.
- TrackPlan (ж-д план пути) — готовый план второго пака.
- Дисциплина: 75 ADR, конформность-аудиты, воспроизводимость.

**Слабости:**
- Материальный авторитет: cutover не завершён (P0-список ADR-053/073) —
  предусловие продаж «прослеживаемости для экспертизы».
- Один человек + агенты: bus factor, нет продаж/маркетинга.
- Продукт не упакован для внешнего пользователя (нет installer/onboarding).

## 4. План по фазам

### Фаза 0 — «Двойной профит» (сейчас, 0–3 мес)
Цель: первые живые деньги + доведение ядра до продаваемого состояния.
1. Закрыть P0 (material authority, ratchet, словарь recovery) — без этого
   нельзя честно продавать «прослеживаемость для экспертизы».
2. Упаковать GDesign-вертикаль: установка «параметры → том» одним
   командным файлом, демо-сайт.
3. Форма: **самозанятость/ИП** (услуги расчётов —最快 легальный вход).
4. Первые 2–3 платных расчёта для знакомых проектных бюро/подрядчиков
   (цена [О]: 50–200 тыс ₽ за том опоры; себестоимость — ваша подписка
   GLM Max $160/мес + время). На этом этапе использование личной подписки
   допустимо (вы — единственный пользователь); фиксируйте токен-расход для
   будущей юнит-экономики.

### Фаза 1 — Компания (3–9 мес)
1. **ООО** (один учредитель — достаточно; для грантов нужно
   юрлицо-МСП) + аккредитация Минцифры ИТ-компании: налог на прибыль 5%,
   взносы 7,6% (с 2026 — 15% в пределах базы, см.
   [Минцифры](https://digital.gov.ru/activity/mery-podderzhki-it-otrasli/nalogovye-lgoty-2)).
2. **Реестр отечественного ПО** (ПП №1236): весь стек собственный —
   реальная редкость; даёт доступ к госзаказу и продажи без НДС
   ([Минцифры](https://digital.gov.ru/activity/mery-podderzhki-it-otrasli/reestry-rossijskogo-i-evrazijskogo-po)).
3. **Сколково**-резидентство: налоги 0% (10 лет), микрогранты до 1,5 млн ₽
   (штат 3–50 — нанять 2 инженеров,
   [services.sk.ru](https://services.sk.ru/service/1));
   параллельно **ФСИ «Старт»** — до 5 млн ₽
   ([fasie.ru](https://www.fasie.ru/programs/programma-start/)).
4. Продукт: подписка «завод опор» для бюро (3–5 пилотов, FDE-модель:
   встраиваем фабрику в их процесс, находим кодифицируем).
5. Перевод инференса на легальные рельсы по модели **BYO-plan**: фабрика
   разворачивается у бюро, и бюро **само покупает свой GLM Team-план /
   API-ключ** (каждый деплой = новый подписчик Z.ai, мы квоты не
   перепродаём — ToS соблюдены). Наш биллинг — только фабрика (подписка +
   за том). Для чувствительных клиентов — уведомление РКН о трансграничной
   передаче ПДн (152-ФЗ, ст. 12; Китай не в перечне адекватных —
   [РКН](https://pd.rkn.gov.ru/cross-border-transmission/form2/)),
   обезличивание или он-прем на open-weights. Фрикция платежей РФ→КНР
   (карты РФ не проходят): решает сам клиент своими каналами, либо тариф
   «инференс включён» на API-биллинге после коммерческого соглашения
   с Z.ai.

### Фаза 2 — Вертикали и гос-орбита (9–24 мес)
1. Rail-пак (TrackPlan → RailAlignmentPack): план/профиль пути,
   нормативные проверки, LandXML. РЖД-экосистема: свой классификатор и
   LOD-требования ([НИИАС](https://niias.ru/projects/kompleksnaya-sistema-bezopasnosti-dvizheniya-na-zheleznodorozhnom-transporte/)) —
   долгий цикл, но это наш «AASHTO-альянс».
2. **РФРИТ** грант (стартапам до 20 млн ₽ —
   [frp22.ru](https://www.frp22.ru/novosti/detail.php?ID=509)) на
   упаковку платформы.
3. Ценообразование: подписка на завод (мес.) + за том; для гос-клиентов —
   годовые контракты через 44-ФЗ/223-ФЗ (нацрежим: при наличии в реестре
   иностранное ПО закупать запрещено — наш ров).
4. ФСТЭК-сертификация (6–12 мес, [О]) — только если пойдём в ГИС/ПДн
   гос-уровня; не раньше, чем окупится.

### Фаза 3 — Международный горизонт (2–4 года)
1. Чистая структура: юрлицо вне РФ (Сербия/ОАЭ для разработки →
   Нидерланды/Германия для ЕС-продаж) + релокация основателя. Прецедент
   реструктуризации: Yandex → Nebius (Амстердам, Nasdaq).
2. Вход в ЕС как **модуль к CDE** (Thinkproject/Dresden,
   [Dalux](https://www.dalux.com/), Nemetschek), не как замена:
   EU BIM-рынок ~$3,2 млрд (2025,
   [Mordor](https://www.mordorintelligence.com/industry-reports/europe-building-information-modelling-market)),
   mandates в UK (2016), Германии (фед. инфраструктура, 2020), Италии
   (2025, контракты >1 млн €).
3. AI Act: автоматизация выпуска документации, скорее всего, **не
   high-risk** (не safety component, не Annex III —
   [Annex III](https://artificialintelligenceact.eu/annex/3/));
   GDPR-стандарт для B2B SaaS (DPA, хостинг в ЕС/ЕЭЗ — фактически
   обязателен в enterprise-тендерах).
4. Open-source ядра (модель-агностичное, без доменных паков) как канал
   глобальной дистрибуции — санкцон-устойчивый; монетизация — enterprise,
   паки, поддержка.

## 5. Юнит-экономика (оценка)

- Агентное производство документа: ~1–5 млн токенов/том (агентные циклы
  до ~1000× одиночной генерации —
  [arXiv:2604.22750](https://arxiv.org/pdf/2604.22750); бенчмарки:
  MetaGPT ~$2/«программа», SWE-bench ~$0,45/задача).
- 500 томов/мес ≈ 1 млрд токенов: API GLM-4.7 ≈ $800–1200/мес; GLM-5.2 ≈
  $1800–2500/мес ([цены Z.ai](https://docs.z.ai/guides/overview/pricing));
  CN Team-план ~$85–170/место.
- Цена тома для бюро [О]: 100–400 тыс ₽ (рынок расчётных услуг). Даже при
  10 томах/мес и цене 150 тыс ₽: выручка 1,5 млн ₽, токен-себестоимость
  <$100, валовая маржа ПО-уровня. Основная себестоимость — ваш время
  и квалификация (ГИП-контроль).

## 6. Риски и митигации

| Риск | Митигация |
|---|---|
| ToS GLM: личная подписка не для B2B | Фаза 0 — можно (личное использование), фаза 1+ — API/Team; модель-агностичная архитектура уже есть |
| Zhipu в Entity List США; квоты менялись (−33% в фев 2026) | Не строить продукт на одной модели; open-weights MIT (GLM-4.5-Air на 2×4090) для он-прем |
| 152-ФЗ: передача ПДн в КНР | Обезличивание промптов; уведомление РКН; он-прем для чувствительных |
| Один основатель | Фаза 1: +2 инженера (требование Сколково-микрогрантов); документированность уже высокая |
| Соблазн «продавать платформу» | Дисциплина клина: продаём тома и сниженный cycle-time, платформа — внутренняя |
| РЖД/гос-циклы (месяцы–годы) | Выживание на частных бюро; гос — фаза 2 |
| Европа заблокирована для РФ-лица | Планировать IP-гигиену с первого дня (не смешивать личные аккаунты и контракты); релокация до первого ЕС-контракта |

## 7. Первые 10 шагов (конкретно)

1. Закрыть P0-список (ADR-053/073 остатки) и восстановить ratchet.
2. Собрать GDesign в устанавливаемый продукт + демо-страница.
3. Оформить самозанятость/ИП; посчитать себестоимость первого платного тома.
4. Продать 2–3 расчёта знакомым бюро (фиксировать всё: токены, часы,
   замечания).
5. Основать ООО, аккредитоваться в Минцифры, подать реестр ПО.
6. Податься в Сколково + ФСИ «Старт» (дедлайны смотреть на fasie.ru).
7. Нанять 2 инженеров (расчётчик + ревьюер-нормоконтроль).
8. Перевести инференс на API/Team; уведомление РКН при первых ПДн.
9. Оформить Rail-пак (TrackPlan) как второй пилотный продукт.
10. К месяцу 9: решение — точка безубыточности на услугах → ставка на
    подписку; начать IP-гигиену для международной структуры.

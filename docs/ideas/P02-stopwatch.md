# Stopwatch with Laps — product idea

A stopwatch web app: start/pause/reset controls with 10 ms precision, lap
capture, and a lap table showing each lap time plus delta to the best lap.

Ship a static web page (HTML/CSS/JS, no build step required). Acceptance is a
working page where start/pause/reset behave correctly at 10 ms precision, the
lap button records the current split into a table, and each row shows the lap
time and its delta versus the best lap so far.

# Click Counter — product idea

A single-page click counter app: one large button, a live count display,
a reset button, adjustable step (1/5/10), and the counter value persists
in localStorage across page reloads.

Ship a static web page (HTML/CSS/JS, no build step required). Acceptance
is a working page where clicking the big button increases the displayed
count by the selected step, reset returns it to zero, and the value
survives a page reload.

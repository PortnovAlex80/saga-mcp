# Tip Calculator — product idea

A tip calculator: bill amount input, tip percentage slider (0–30), number of
people, and outputs showing tip total, grand total, and per-person amount
with rounding up/down options.

Ship a static web page (HTML/CSS/JS, no build step required) that opens and
works directly in a browser. Acceptance is a working page where entering a
bill, moving the slider and people count immediately updates all outputs,
and rounding up/down options behave correctly.
